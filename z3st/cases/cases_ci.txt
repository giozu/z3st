# CI case list, consumed by non-regression_github.sh
#
# A tight subset of the local suite (non-regression_local.sh), chosen so that CI
# stays a per-commit gate rather than a nightly job. Membership rule:
#   - a stable output/non-regression_gold.json, and
#   - it exercises a physics path no other listed case reaches.
#
# Budget: 14 min 47 s total, from the times measured by a full local
# suite run on 2026-08-09. Most cases are well under a minute; two are not, and
# they are listed with their cost because they buy coverage nothing else does.
# Re-measure before adding anything: ./non-regression_local.sh prints per-case times.
#
# Every model is now reached by at least one gold-carrying case. The two gaps this
# header used to record are closed:
#   cluster_dynamic_model.py -- verification/cluster/mass_conservation_1D, 9 s, listed below.
#   contact_model.py         -- never was a gap. contact is configured as a BLOCK,
#                               models.contact: {surface_a: ..., ...}, and Config takes
#                               bool() of it, so grepping "contact: true" finds nothing
#                               while six cases enable it. Four carry a gold: shrink_fit,
#                               shrink_fit_disk, shrink_fit_disk_3d and pwr_rod_2D (the
#                               last excluded from the local suite, see suite_exclude.txt).
#                               fg_test_2D and creep_shrink_fit_2D write a verdict but
#                               have no gold, so nothing discovers them.
#
# Run `python -m z3st.utils.audit_checks` to re-derive all of the above; it is where
# the goldless-case list comes from and takes four seconds.
