IAEA VP2 - IWGFR/75 App. 2, EXAMPLE 2: single wrapper, non-linear thermal gradient
==================================================================================

Case
----
As the former VP1 (same geometry, mesh, material, clamp, axial T profile); only the
section temperature changes. Thermal model off: T is imposed as a material eigenstrain.
(VP1 now solves T from a Dirichlet expression, see ../VP1/VP1_notes.txt.)

  geometry   D = 0.153464101 m (outer circumscribed), t = 3 mm, H = 4 m, orientation vertical
             mid-wall corner-to-corner depth 0.150 m; mesh nf 8, nt 1, nz 400 (hex, 38496 nodes)
  material   E 1.7e+11 Pa, nu 0.3, alpha 1.8e-5 1/K, T_ref 400 C (673.15 K)
  BC         bottom fully clamped (u = 0); no thermal BCs
  T          below the core (z < 1.5 m): 400 C everywhere
             above the core top (z > 2.5 m): corners 1, 2, 6 at T1 = 500 C, corners 3, 4, 5 at T2 = 550 C
             across the core: linear ramp in z, as VP1
             section: T1 for h <= -D/4, linear for |h| < D/4, T2 for h >= D/4
             (h along the hot-corner direction PHI_HOT = -pi/2, h = -y; hot corner 4 at -y)
  coords     x, y, z global (IAEA: X east, Y north, Z up); local frame of hex_post:
             xi through the wall, s along the flat at mid-wall, p mid-wall perimeter
  solver     3d, mechanical linear (direct_mumps), 1 static step at t = 0, xdmf output
             (4 steps until 2026-10-27, identical fields)

Closed form
-----------
  kappa(z) = alpha int theta h dp / int h^2 dp = C alpha (T2 - T1) / D
  VP1 (T linear in h): C = 1; VP2: C = 4/3 -> URP bow 16.333 mm against 12.25 mm of VP1.
  Mean section T is (T1 + T2) / 2 as in VP1: u_z is the VP1 one.
